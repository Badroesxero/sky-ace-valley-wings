# Sky Ace — Valley Wings

An original, complete flight game in plain static files. Chase view behind
the aircraft over a recognisable river valley — ridges, a winding river,
meadows, forest and one runway — with working cockpit instruments, three
missions with different goals, and landings that are judged differently
from crashes.

No build step, no dependencies, nothing loaded from the network.
Everything — terrain, aircraft, instruments, sound — is generated by code.

## How to play

Open `game/index.html` in desktop Chrome (double-click the file, or serve
the folder with any static file server). The game runs fully offline.

You start airborne over the valley, heading north. The current mission
goal is always stated in the banner at the top of the screen.

### Controls

| Key | Action |
| --- | --- |
| ↑ / ↓ | Climb / descend (pitch) |
| ← / → or A / D | Bank and turn |
| W / E | Throttle up |
| S / Q | Throttle down |
| Enter | Start mission / next mission |
| P or Esc | Pause |
| R | Restart current mission |
| M | Mute / unmute sound |

### Flight model notes

- **Throttle discipline pays.** Climbing bleeds airspeed, diving gains it,
  and full throttle does not cancel gravity. Plan climbs.
- **Banking turns.** Turn rate comes from bank angle and airspeed — fast
  flight turns wide, slow flight turns tight.
- **Stall.** Below about 22 m/s (≈43 kt) the nose drops, sink grows and a
  STALL warning flashes. Controls stay responsive, but recover speed first.
- **Landing ≠ crash.** A touchdown only counts as a landing on the runway
  strip, roughly aligned with it, at or below 32 m/s and sinking no faster
  than 3.5 m/s. Anything else is a crash, and the game tells you why.

## Missions

1. **Valley Rings** — fly through 6 golden rings, in order, over the river.
2. **Checkpoint Dash** — reach the far checkpoint beacon within 95 seconds.
3. **Land at Valley Field** — land gently on the runway (threshold 4,300 m
   north, strip to 5,100 m). Completing it finishes the campaign.

Missions unlock in order and each completed mission offers the next.

## Instruments

Bottom panel, all live: airspeed (kt), altimeter (ft), heading, artificial
horizon, throttle gauge (%), vertical speed (fpm), height above ground
(AGL, ft), position, and a stall warning.

## Screenshots

The three files in `screenshots/` are real renders of this game's own
code, captured in headless Chromium at 1280×720. They are staged
deterministically by `game/js/shots.js` — open the game with a query
string and the scene is set up with the game's own modules, no human
input:

| File | URL query | Scene |
| --- | --- | --- |
| `1-start.jpg` | `?shot=start&seed=1` | Mission briefing: aircraft over the valley, terrain and first ring ahead, goal banner and briefing panel |
| `2-play.jpg` | `?shot=play&seed=1` | Chase view mid-flight: 12 fixed-step seconds under a simple autopilot steering for the first ring, live instruments |
| `3-end.jpg` | `?shot=end&seed=1` | End state: the landing mission's touchdown judged by the real `judgeTouchdown` — smooth touchdown, campaign complete |

The same seed always renders the same frame (a re-capture of the
`play` scene was byte-identical). Without a `?shot=` query the game
plays normally. See `PENDING.md` for the full submission status,
including the capture-method note and what is still owed.

Each JavaScript file has exactly one job, named after that job.

## Sound

Engine hum follows throttle, wind follows airspeed, and rings, checkpoints,
success and crashes have short synthesised cues — all via WebAudio, all
generated in `audio.js`. Press M to mute.
